# Bharat AI Dataset Guidelines

## 1. Dataset requirements
- Every image must have a traceable source.
- Every image must have an identifiable license.
- Commercial-use permission must be verified.
- Captions must accurately describe the image.
- Duplicate and corrupted images must be removed.

## 2. Prohibited data
- Images scraped from Google without permission.
- Copyrighted images with unknown licensing.
- Non-commercial-only images for commercial training.
- Images with unclear consent or usage rights.

## 3. Metadata
Maintain source, source URL, creator, license,
attribution requirements, consent status and category.

## 4. Dataset splits
- train: model training
- validation: tuning and evaluation
- test: final evaluation

Keep test data separate from training data.

## 5. Quality
Review image quality, caption accuracy, duplicates,
cultural representation and licensing before training.
